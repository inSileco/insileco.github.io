The goal of this workshop is to introduce participants to the development of interactive tools for exploring and visualizing raster-based spatial data in R. Through guided exercises, participants learn how to move beyond static maps by building interactive dashboards that allow users to pan, zoom, click, and otherwise engage with spatial layers dynamically. The workshop emphasizes using modern mapping libraries such as `leaflet` and `tmap`, and helps participants assemble these components into shareable, browser-based outputs, including HTML dashboards and simple Shiny applications.

More broadly, the workshop is designed to build practical capacity in translating spatial analyses into decision-support or communication tools. Participants gain experience connecting data processing, visualization, and user interface design, allowing them to create applications where users can control how spatial information is displayed and explored. By the end of the session, attendees should understand the basic architecture of interactive mapping workflows in R and be able to adapt these techniques to their own environmental, research, or data-communication projects.
