The goal of this workshop is to introduce participants to the fundamentals of version control using Git and collaborative development using platforms such as GitHub. The workshop focuses on helping participants understand how to track changes in code, data, and documents over time, allowing them to safely manage project history, recover from mistakes, and maintain organized and transparent analytical workflows. Participants typically learn core concepts such as repositories, commits, and project versioning, which are considered essential components of modern research and data-science practices. 

More broadly, the workshop aims to strengthen participants’ ability to collaborate efficiently on shared projects and improve the reproducibility of their work. Through hands-on exercises, participants learn how to share projects through remote repositories, contribute to collaborative workflows using branching and pull requests, and adopt best practices for managing code and documentation. By the end of the workshop, participants should be able to use Git-based workflows to support teamwork, maintain reliable project histories, and facilitate the transparent communication and reuse of analytical work.
